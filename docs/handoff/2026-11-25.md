## Shipped today

1. **`b338aa7` Pipelock chain replay.** The receipt chain is recomputed from
   genesis: `chain_seq` increments, `chain_prev_hash` is the SHA-256 of the
   previous canonical envelope, a break/gap/reorder rejects the batch, and a
   mid-chain slice needs `--allow-partial-chain` and is stored unverified.
2. **`f2095ce` Pipelock signing-key rotation.** `--pubkey` takes a
   comma-separated set (or one per line in `--pubkey-file`); a
   `key_transition` boundary is replayed only when every segment key is pinned.
   The marker is continuity metadata, not trust delegation.
3. **`c3021f9` Control-test reminders.** `opengrc:controls:testing:notify`
   sends due (warning) and overdue (danger) notifications to the implementation
   owner once per stage and test date, scheduled daily at 07:00.
