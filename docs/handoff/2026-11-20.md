## Open items, stated plainly

1. **Streaming monitoring is not built.** Connectors run on a schedule and write
   evidence after the fact; there is no event stream or near-real-time path.
2. **Approval limits.** No delegation, reminders, email/chat notification or
   per-field conditional routing.
3. **Risk appetite is global.** A single heat-map threshold exists; per-category
   appetite is still a documented decision, not a setting.
4. **Remediation is a task list, not a project plan.** No dependencies,
   milestones, ticket sync or automatic finding closure.
5. **Evidence retention is manual.** Files are private, hashed and ledger-backed,
   but there is no per-file expiry or retention rule.
6. **Regulatory change is not a feed.** The register is maintained by a person; no
   subscription, revision diff or automatic applicability decision.
7. **DLP recall is not measured.** The quality page measures false positives; it
   does not prove the detectors catch everything.
8. **Crosswalks are reviewed, not automatic.** No title/similarity matching and no
   bulk import.
9. **Nth-party risk is flat.** Subcontractors are recorded on a vendor; there is no
   recursive supplier graph or inherited score.

## If returning to OpenGRC

Start with `git status` and `php artisan opengrc:doctor`. If the schema changed,
regenerate `database/migration-manifest.json` and the schema snapshot. Do not edit
an applied migration; add a new one.
