# Skills notices

The skills in this directory are original works written for OpenGRC.

They follow the `SKILL.md` convention used by the OpenCyberRange project
(frontmatter with `name` and `description`, imperative guidance, optional
`references/` and `templates/`). The structure and the habit of recording
operational lessons came from that project; no OpenCyberRange text is copied here.

OpenCyberRange is distributed under a non-commercial licence. Do not copy its skill
files, course content, or lab material into this repository without checking that
licence first. Rewrite the idea in OpenGRC's own words, as these skills do.

| Skill | Scope |
|---|---|
| `opengrc-platform-architecture` | Code map, conventions, feature checklist |
| `opengrc-grc-domain-model` | Vocabulary and invariants for GRC records |
| `opengrc-framework-mapping` | Importing standards and crosswalking frameworks |
| `opengrc-training-scenario-authoring` | Hands-on GRC exercises and rubrics |
| `opengrc-opencyberrange-integration` | Event contract and evidence ingestion |
| `opengrc-upgrade-and-compatibility` | Version policy, upgrade gates, rollback |
| `opengrc-security` | Threat model, controls, defaults that need an ADR |
| `opengrc-privacy` | Personal data map, disclosure, retention, erasure |
| `opengrc-design` | Visual language, colour semantics, states, accessibility |
| `opengrc-user-interface` | Filament resources, pages, tables, hooks, portal UI |
