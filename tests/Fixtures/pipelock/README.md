# Pipelock fixtures

`valid-single.json` is the published `valid-single.json` conformance fixture from
`pipelab-org/pipelock` (`sdk/conformance/testdata`, Apache-2.0). It is kept
verbatim so the verifier is tested against the producer's canonical bytes, not a
fixture generated by this repository.

Source: https://github.com/pipelab-org/pipelock/blob/main/sdk/conformance/testdata/valid-single.json

`valid-chain.jsonl` and `broken-chain.jsonl` are derived from the published
`valid-chain.jsonl` and `broken-chain.jsonl`. Each line is the `detail` field of
one flight-recorder entry: the bare receipt envelope, byte-for-byte the producer's
JSON value, with the recorder wrapper removed so the importer's bare-receipt path
can be exercised. The chain links, signatures and the intentional break at
`chain_seq` 3 in `broken-chain.jsonl` are unchanged.

The recorder entry hash is a different chain from the receipt chain and is not
part of these files; see the Pipelock action-receipt spec.

Sources:
- https://github.com/pipelab-org/pipelock/blob/main/sdk/conformance/testdata/valid-chain.jsonl
- https://github.com/pipelab-org/pipelock/blob/main/sdk/conformance/testdata/broken-chain.jsonl
